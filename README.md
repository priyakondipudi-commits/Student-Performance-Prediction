# Student Performance Prediction using Machine Learning

## Project Description
This project predicts whether a student will Pass or Fail based on:
- Study Hours
- Attendance
- Previous Marks
- Assignment Submission

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Machine Learning Algorithm
- Logistic Regression

## Features
- Data Analysis
- Data Visualization
- Model Training
- Model Prediction
- Save and Load Model
- User Input Prediction

## Project Files
- student_prediction.ipynb
- dataset.csv
- student_model.pkl
- README.md
